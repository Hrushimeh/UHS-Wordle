# 🍅 UHS-Wordle

Hello and welcome to the UHS-Wordle repository!

## 🍅 About

This is a holiday Wordle game created for Unionville High School. This custom-made word game brings the enjoyment of Wordle to UHS, developed by the talented Coders United team at our home school.

This game is designed for our school community to enjoy and relax during the holiday season. Everyone knows and enjoys Wordle, so we decided to bring this fun experience to UHS with a new word to guess daily.

## 🍅 Features

- 🍅 Built using TypeScript, React, and Next.js
- 🍅 New word puzzle daily
- 🍅 Holiday-themed experience for the UHS community
- 🍅 Carefully tested to ensure a pleasant user experience

## 🍅 Getting Started

### Prerequisites

- Node.js installed on your system
- npm or yarn package manager

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

To run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

```bash
npm run build
npm start
```

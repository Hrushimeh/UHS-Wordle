# UHS-Wordle

Hello and welcome to the UHS-Wordle repository! 👋

## About

This is a custom Holiday Wordle game created for Unionville High School. The game is built using TypeScript, React, and Next.js to provide an enjoyable and relaxing experience during the holiday season.

Everyone knows and enjoys Wordle, so we decided to bring this enjoyment to UHS with a custom-made version from the beloved Coders United at their home school. We made sure that there were no bugs and errors so that the users of UHS can have a pleasant time, with a new word daily.

## Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-org/UHS-Wordle.git
   cd UHS-Wordle
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Run the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to play the game.

### Building for Production

```bash
npm run build
npm run start
```

## Features

- Daily word challenges
- Built with modern web technologies (TypeScript, React, Next.js)
- Responsive design with Tailwind CSS
- Smooth animations with Framer Motion
- Firebase integration for data management

## Technologies Used

- **TypeScript** - Type-safe JavaScript
- **React** - UI component library
- **Next.js** - React framework for production
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Firebase** - Backend services

# UHS-Wordle

Welcome to UHS-Wordle! This is a custom Wordle game created for Unionville High School to bring joy and relaxation to students during the holiday season.

## About

This holiday Wordle game is built specifically for Unionville High School. Everyone knows and enjoys Wordle, so we decided to bring this enjoyment to UHS and make sure that the school has a custom-made Wordle from their beloved Coders United at their home school.

We built this using TypeScript, React, and Next.js, ensuring there are no bugs and errors so that the users of UHS can have a pleasant time with a new word daily.

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

To run the development server:

```bash
npm run dev
```

To build for production:

```bash
npm run build
npm start
```

Visit `http://localhost:3000` to play the game!

## Features

- Daily word puzzles
- Custom word list tailored for UHS
- Smooth animations and interactive keyboard
- Mobile-friendly responsive design

## Technology Stack

- **TypeScript** - Type-safe JavaScript
- **React** - UI component library
- **Next.js** - React framework for production
- **Tailwind CSS** - Utility-first CSS framework
- **Firebase** - Backend services
- **Framer Motion** - Animation library
